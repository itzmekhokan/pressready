# Contributing to Pressready

Thank you for your interest in contributing! Here's how it works.

## Ownership & copyright

Pressready is created and maintained by **Khokan Sardar** ([@itzmekhokan](https://github.com/itzmekhokan)).

## How to contribute

1. **Open an issue first** for anything significant — a bug report, feature idea, or question. Discuss before coding.
2. **Fork → branch → PR.** Keep PRs focused; one thing per PR.
3. **Follow existing code style** — tabs for indentation, WordPress coding conventions for PHP.
4. **Tests:** if your change touches the scanner logic, add or update a case in `tests/smoke.php`.

## What gets accepted

- Bug fixes with a clear reproduction case
- Performance improvements with measured evidence
- New WP/PHP coverage with a rationale
- Documentation improvements

## Code of conduct

Be respectful and constructive. Issues and PRs that are rude, spammy, or off-topic will be closed.
